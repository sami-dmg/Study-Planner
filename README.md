# Study Planner 📚⏱️

A native Android productivity application designed to help students organize academic tasks, schedule curriculum calendars, and track daily goals.

## ✨ Features
- **Task & Checklist Manager:** Keep track of homework, exams, and daily assignments.
- **Calendar Organization:** Structured timeline planning for academic terms.
- **Lightweight Storage:** Local on-device persistence for offline access.

## 🛠️ Tech Stack
- **Language:** Java
- **UI Components:** Android Studio, Material Design
